# UP-T301 定高与定点闭环测试流程

## 1. 控制结构

当前只使用 P905/P310 上的 UP-T301 UPIX 数据，旧 TPF/LC08 软件 I2C 驱动
已经移除。数据链沿用 RA6M5 方法：

```text
TOF 5点平滑 + 垂直加速度互补 → 高度/垂直速度
UPIX物理速度 → 陀螺补偿 → 0.85/0.15低通 → 积分位置
高度位置环 → 垂直速度环 → 基础油门修正
水平位置环 → 水平速度环 → Roll/Pitch目标 → 原姿态串级环
```

UP-T301 已输出物理速度，导航层不重新按光流积分计算速度。模块安装适配集中
在 `project_config.h`：`FLOW_NAV_SENSOR_SWAP_XY`、
`FLOW_NAV_SENSOR_X_SIGN`、`FLOW_NAV_SENSOR_Y_SIGN`。

CH6 模式：

- 低档：原手动姿态和油门。
- 中档：进入时锁定当前高度；Roll/Pitch 仍由飞手控制。
- 高档：锁定当前高度和位置；Roll/Pitch 摇杆缓慢移动位置目标。
- 光流失效：高档自动降级为定高并把 Roll/Pitch 交还飞手。
- TOF 失效：退出全部导航闭环，回到手动控制。

## 2. 第一级：SAFE 导航数据验证

1. 拆除全部螺旋桨，断开 ESC 动力。Debug/Release 不增加任何 profile 宏，
   执行 `clean all` 后烧录。
2. 模块垂直朝向带纹理地面，高度 0.3～1.0 m；VOFA+ 选择 JustFloat、
   16 通道。
3. 静止 10 s：I7/I8/I9 应持续为 1；I0 接近实测高度，I1、I4、I5 接近 0。
4. 保持姿态和高度，沿机体前后平移：向前时 I4、I2 应增加，向后时应减少。
5. 沿机体左右平移：向右时 I5、I3 应增加，向左时应减少。
6. 若轴交换，只把 `FLOW_NAV_SENSOR_SWAP_XY` 改为 1U；若某轴符号相反，
   将对应 `FLOW_NAV_SENSOR_*_SIGN` 改为 -1.0f。修改后必须重复第 3～5 步。
7. 原地小角度 Roll/Pitch 转动而不平移，I4/I5 经短暂响应后应回到 0 附近，
   用于确认 RA6M5 同款陀螺补偿方向。

通过条件：连续 60 s 导航就绪；静止无持续单向位置漂移；四方向符号全部符合
机体系约定。此阶段 I10～I13 为 0 是正常的，因为 SAFE 不运行控制器。

## 3. 第二级：FLOW_HOLD_SHADOW 拆桨影子闭环

1. 新建专用构建配置，只添加 `PROJECT_BUILD_PROFILE=3U`；不得添加
   `PROJECT_DANGEROUS_BUILD_ACK`。执行 `clean all` 后烧录。
2. 保持拆桨、ESC 动力断开，按正常顺序 CH5 低档、油门最低上电，再 CH5
   高档解锁并将油门缓慢抬离低油门区。四路执行器必须始终为 1000 us。
3. CH6 中档：I13 应变为 1。进入瞬间 I12 接近 0；向上抬高机架使测量高度
   增大时 I12 应为负，向下靠近地面时 I12 应为正。
4. CH6 高档：I13 应变为 2。保持摇杆回中，向前推移机架时 I11 应为正
   （机头抬起制动）；向右推移时 I10 应为正；反向移动时符号相反。
5. 高档下遮挡光流但保持 TOF：I13 应降为 1，I10/I11 回到手动目标。
   再遮挡 TOF：I13 应降为 0，I12 回到 0。
6. CH5 低档后 I10～I13 应立即清零，四路仍为 1000 us。

通过条件：模式切换无目标突跳；高度和位置反馈方向全部是负反馈；任一传感器
失效均按上述路径降级；全程执行器没有离开 1000 us。

## 4. 第三级：系留定高

只有前两级全部通过才建立专用系留配置：

```text
PROJECT_BUILD_PROFILE=1U
PROJECT_DANGEROUS_BUILD_ACK=0x54455448UL
```

1. 使用限高系留、护目镜、隔离区、助手和可立即断电的电源；首次只在
   CH6 低档验证原姿态闭环。
2. 稳定悬停且高度大于 0.3 m、地面纹理清楚时切 CH6 中档。首次保持 2～3 s
   即切回低档，逐次延长到 10 s。
3. 观察 I18 高度、I19 垂直速度和 I17 基础油门。高度振荡时先降低高度速度环
   `Kp`，响应太慢再小步增加；最后才调整 `Ki`。每次只改一个参数。
4. 中档连续 10 s 无发散、无输出顶限、切换无明显跃升，才进入定点测试。

## 5. 第四级：系留定点

1. 机架处于中档稳定定高后切 CH6 高档，首次保持 1～2 s 后退回中档。
2. I20/I21 偏离锁定点时，I24/I25 必须给出与第二级一致的制动方向；目标角
   首轮硬限制为 ±5°。
3. 先调位置外环：偏移 0.2 m 后回位速度平缓且不超过 I22/I23 的 300 mm/s
   目标上限。再调速度环，使回位不过冲、不持续摆动。
4. 分别进行前后、左右扰动；最后才做两轴组合扰动。每轮发现振荡、导航失效、
   倾角异常或输出接近上限，立即 CH6 低档或 CH5 停机。
5. 完成后删除 profile/ack 宏，`clean all` 重建 SAFE 并重新烧录。

首次参数是保守起点，不复制 RA6M5 的 PID 数值；机架尺寸、动力和模块尺度不同，
最终增益只能根据本机架系留记录确定。
