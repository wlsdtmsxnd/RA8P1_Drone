# RA8P1 飞控迁移状态

## 迁移基线

- 目标机架与 `RT1064_Drone_10inch` 相同。
- `RT1064_Drone_10inch` 提供已经验证的 IMU 安装方向、CRSF、数传、
  电机顺序和安全逻辑。
- `D:\Renesas\old_fly` 的 RA6M5 工程仅作为完整四轴控制流程参考，
  不复制其 FSP 生成文件和针对小机架的 PID 参数。

## 硬件映射

| 功能 | RA8P1 引脚 | 外设 |
|---|---|---|
| ICM42688 SCK | P415 | SPI1 RSPCK |
| ICM42688 MOSI | P708 | SPI1 MOSI |
| ICM42688 MISO | P709 | SPI1 MISO |
| ICM42688 CS | P710 | GPIO，低有效 |
| CRSF RX / TX | P602 / P603 | SCI0，420000 baud |
| 3DR 数传 RX / TX | P802 / P801 | SCI2，57600 baud |
| Holybro GPS RX / TX | P715 / P714 | SCI4，115200 baud |
| Holybro GPS compass SDA / SCL | P514 / P515 | IIC2 |
| M1 / M2 | P700 / P701 | GPT5 A / B |
| M3 | P109 | GPT10 A |
| M4 | P702 | GPT6 A |

电机顺序沿用 RT1064 实机记录：M1 左前、M2 右前、M3 右后、M4 左后。
四路 ESC PWM 为 50 Hz，范围 1000-2000 us，上电和任何故障状态均保持
1000 us。

## 已完成

- ICM42688 SPI 驱动、500 Hz Mahony 姿态解算和静止陀螺零偏标定。
- 同步 RT1064 实测 FRD 轴向：X 前、Y 右、Z 下；加速度比力取反后参与
  重力校正。
- CRSF 16 通道解析、300 ms 失联判定和 3DR/VOFA JustFloat 数传。
- 四路 GPT PWM、电机脉宽限幅和上电安全输出。
- CH5 解锁：启动后必须先看到低档；CH3 低于 1050 us 且 CH5 高档保持
  1 秒才进入 ARMED。CH5 低、遥控失联或 IMU 更新失败立即停机。
- 编译期保护的电调行程校准和 M1-M4 无桨顺序测试。
- 无桨顺序测试必须由低油门下 CH5 低到高主动触发；CH5 低、油门抬高或
  遥控失联都会立即恢复 1000 us。台架模式可通过 VOFA 观察四路命令、
  当前阶段、活动电机和输出错误。
- 纯摇杆混控波形测试已通过：Roll 右打增加 M1/M4，Pitch 后拉增加
  M1/M2，Yaw 右打增加 M2/M4；反向操作对应关系相反。测试仅验证
  混控矩阵，未接入姿态或陀螺反馈。
- 仅 IMU 回水平角度反馈测试已通过：Roll/Pitch 修正斜率约为
  -1.5 us/deg，四个倾斜方向均生成反向回水平修正；该阶段未接入
  角速度内环或 Yaw 控制。
- 仅 IMU 角速度阻尼测试已通过：X/Y/Z 修正斜率约为 -0.25 us/(deg/s)，
  三轴正反方向均产生反向阻尼；静止有效段四路差值最大 1 us，撤防后
  四路恢复 1000 us。
- Roll/Pitch 保守串级自稳波形测试已通过：实测修正约为角度项
  -0.75 us/deg 与角速度项 -0.25 us/(deg/s) 之和，正反倾斜均正确，
  有效测试段未发生保护误停。
- 受限遥控目标角度串级波形测试已通过：Roll/Pitch 指令均覆盖正负满杆，
  实测指令增益约 7.5 us/单位，所有强指令样本的混控方向均正确。
- 受限 Yaw 目标角速度波形测试已通过：Yaw 指令覆盖正负满杆，实测指令
  增益约 7.47 us/单位，正反方向混控正确且安全状态正常撤防。
- 统一三轴控制路径的断电综合波形测试已通过：Roll/Pitch 两组半杆组合的
  电机叠加关系正确，补测 Yaw 正负半杆和满杆均正确，测试期间无保护误停。
- 已在用户明确确认拆桨、固定机架和周围净空后启用专用无桨通电综合模式；
  该模式带独立 ESC 动力授权、输出软启动和更保守的目标及保护限幅。
- 无桨通电记录的控制器侧检查已通过：三次启动斜率均为 500 us/s，撤防在
  下一遥测帧恢复四路 1000 us，三轴指令差动方向正确，最高输出 1159 us。
- 无桨通电机械响应已通过：四个电机均能稳定启动并在撤防后立即停转，
  Roll/Pitch/Yaw 六个摇杆方向和四个轻微倾斜方向的实际快慢变化均符合
  预期，未观察到抖动、异响、失步或机架松动。
- 统一控制器影子运行已通过：有效记录约 107.04 秒，三轴正负摇杆动作的
  指令/修正符号一致率均为 100%，撤防下一遥测帧全部清零；示波器确认
  四路实际 GPT 全程为 50 Hz、1000 us。
- 已新增独立 `pid_controller` 内核，具备显式周期、输出/积分限幅、测量值
  微分滤波、条件积分抗饱和和统一复位。当前五个姿态控制器仍保持
  `Ki=Kd=0`，没有复制 RA6M5 参数，也没有启用实际电机输出。

## 尚未完成

- RT1064 工程当前也尚未把角度环、角速度环 PID 输出接入电机；RA8P1
  已迁移双环控制结构，但仍在影子模式中，实际四路保持 1000 us。
- 新 PID 内核接管 P-only 双环后的数值等效性尚需再用一份短记录确认；
  通过前不启用积分、微分或任何实际电机输出。
- 当前控制器仅使用保守的角度 P 外环和角速度 P 内环，不包含 Yaw 航向
  保持、积分项、微分项或经过推力闭环验证的可飞参数。
- 尚未进行带桨推力测试、系留测试、首次离地测试和实际 PID 调参；不得因
  无桨测试通过而判定项目已经可以带桨飞行。
- RA6M5 的机架尺寸和动力系统不同，其 PID 数值不能直接使用。
- 定高、光流、低电压和传感器冗余保护尚未迁移。
