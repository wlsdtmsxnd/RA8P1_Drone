# RA6M5 同款 TPF/LC08 光流首次测试

本阶段的新驱动只采集和发送数据，不参与姿态、位置或电机控制。原有
`up_tof` UART 驱动保留不变。新模块当前使用 P406（SCL）、P409（SDA），
协议、I2C 地址和安装方向沿用 RA6M5。

TPF 与 UART TOF 均由导航传感器采集任务维护，3DR 遥测初始化或发送失败
不会停止光流采集；遥测线程只读取已经发布的数据快照。

当前无额外宏的 SAFE 构建默认显示 UP-T301 UPIX UART 诊断。若要恢复这里的
TPF 专用诊断，在 SAFE 构建中显式设置 `TELEMETRY_SOURCE=0U`（CRSF 档位仅作
选择开关），即可启用 17 通道、50 Hz 的 TPF 数据；SAFE 固件不会授权执行器
输出。通道定义以 `telemetry_layouts.md` 为准。

如果以后需要再次换脚，可按 `pin_resource_inventory.md` 中的档位
更换一组软件 I2C 引脚；固件配置与实际接线必须同时更改。

## VOFA+ 通道

- I0：原始测距，m。
- I1：按 Roll/Pitch 倾角修正后的垂直高度，m。
- I2、I3：模块原始 X/Y 速度字节。
- I4、I5：按 RA6M5 比例换算的 X/Y 速度，mm/s，未做角速度补偿。
- I6、I7：角速度补偿并低通后的 X/Y 速度，mm/s。
- I8：光流质量值。
- I9：数据有效标志，正常时为 1。
- I10：成功样本计数，约每 30 ms 增加一次。
- I11：I2C ACK 错误计数。
- I12：I2C 总线错误计数。
- I13、I14：Roll/Pitch，deg。
- I15、I16：Gyro X/Y，deg/s。

## 第一步：拆桨通信和高度

1. 拆下四片桨，保持飞控和模块安装方向与 RA6M5 一致。
2. 先断电核对 P406/SCL、P409/SDA、供电和地线，再刷入固件。
3. 上电后不要解锁，观察 I9～I12：I9 应为 1，I10 应持续增加，
   I11/I12 不应持续增加。
4. 依次把模块水平放在有纹理、无强反光的地面上方约 0.2、0.5、1.0、
   1.5 m；I0 应随高度变化，水平时 I1 应接近 I0。
5. 若 I11/I12 连续增加，立即停止方向测试，先排查地址、接线、电平和
   供电；若 I9～I12 始终全为 0，则重点检查 P406/P409 配置和固件是否更新。

## 第二步：拆桨方向和角速度补偿

1. 保持机身水平，分别向机头前、后、右、左平移，每个方向约 0.5 m，
   记录 I2/I3 与 I6/I7 的正负号。
2. 原地不平移，分别做小幅前倾、后仰、右倾、左倾。I4/I5 可能因视场
   转动产生输出；补偿后的 I6/I7 应明显更接近 0。
3. 重复动作两次，确认方向符号可重复且 I8 没有在运动期间掉到异常低值。
4. 保存本次 CSV，并注明四个平移方向的时间顺序。

## 通过条件与下一阶段

只有在高度连续、有效标志稳定、错误计数不增长、四方向符号可重复，且
原地倾转时补偿速度小于未补偿速度后，才进入“影子位置环”阶段。影子环
只计算建议 Roll/Pitch 修正量并记录，不写入电机；确认符号正确后再考虑
低增益系留悬停。当前不要带桨测试光流闭环。
