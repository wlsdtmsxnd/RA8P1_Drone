# RA8P1 当前引脚资源与 TPF 软件 I2C 平替清单

本清单以当前工程 `R7KA8P1KFLCAC`、FSP 配置和源码运行时 GPIO 使用为准。
工程选择的是自定义板，仓库中没有 PCB 原理图，因此“固件未占用”不自动
代表“PCB 已引出且没有连接板载器件”。实物换线前仍需查 PCB 网络或测量。

## TPF 可直接选择的编译期档位

这些档位均使用软件 I2C、3.3 V 内部上拉和开漏输出。每组第一个管脚是
SCL，第二个是 SDA；默认档位没有改变。

| `TPF_FLOW_PIN_PAIR` 档位 | SCL | SDA | 状态 |
|---|---:|---:|---|
| `TPF_FLOW_PIN_PAIR_P406_P409` | P406 | P409 | **当前默认、用户选择** |
| `TPF_FLOW_PIN_PAIR_P411_P412` | P411 | P412 | RA6M5 原接线，可回退 |
| `TPF_FLOW_PIN_PAIR_P413_P414` | P413 | P414 | 首选备用 |
| `TPF_FLOW_PIN_PAIR_P408_P409` | P408 | P409 | 可选备用 |
| `TPF_FLOW_PIN_PAIR_P400_P401` | P400 | P401 | 可选备用 |
| `TPF_FLOW_PIN_PAIR_P402_P403` | P402 | P403 | 可选备用 |
| `TPF_FLOW_PIN_PAIR_P404_P405` | P404 | P405 | 可选备用 |
| `TPF_FLOW_PIN_PAIR_P406_P407` | P406 | P407 | 可选备用，与当前档位互斥 |

P410 在当前固件中也没有使用，但为了让接线保持成对、便于检查，没有单独
建立包含 P410 的预设档位。当前 P406/P409 档位启用时，P407 空闲；P415
已用于 IMU 时钟，不能作为 TPF 备用。

## 当前固件明确占用：不得直接平替

| 功能 | 引脚 | 处理结论 |
|---|---|---|
| M1/M2/M3/M4 | P700/P701/P109/P702 | 电机 PWM，禁止复用 |
| ICM42688 | P415/P708/P709/P710 | SPI 与片选，禁止复用 |
| CRSF | P602/P603 | 飞行遥控，禁止复用 |
| 3DR/VOFA | P802/P801 | 当前测试遥测，禁止复用 |
| SWD | P210/P211 | 下载调试，禁止复用 |
| 5V_EXT 使能 | P206 | 电源控制，禁止复用 |
| 状态 LED | P110 | 运行时翻转，不直接复用 |
| UART9 调试输出 | P208/P209 | 任务正在使用，不直接复用 |

## 只有停用原功能后才可复用

| 当前/预留功能 | 引脚 | 条件 |
|---|---|---|
| 原 `up_tof` UART | P905/P310 | 本次要求保留旧驱动，因此不可用于新 TPF |
| GPS | P715/P714 | 只有确认不再使用 GPS 并停用 SCI4 后才可复用 |
| GPS 罗盘 IIC2 | P514/P515 | 已在硬件规划中预留，不建议占用 |
| UART9/J-Link 文本输出 | P208/P209 | 删除/停用对应线程和 SCI9 后才可复用 |

## 其他未配置 GPIO

软件 I2C 原理上还可使用封装内其他普通 GPIO，但当前仓库缺少自制 PCB
原理图，无法确认它们是否悬空、是否引到连接器或是否接了板载器件，所以
不将其列为“可直接平替”。若 P4 备用组在实物上均未引出，应先提供 PCB
原理图或连接器引脚表，再从剩余 GPIO 中增加新的编译期档位。
